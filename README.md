## 📌 Project Overview

This project benchmarks multiple deep learning models for underwater image enhancement. Each model processes the same underwater images independently, and the enhanced outputs are compared with the corresponding reference images using standard image quality metrics.

A total of **eight enhancement models** are evaluated, including a combined **WaterNet + Real-ESRGAN** model. All models are executed independently under the same evaluation framework to ensure a fair performance comparison.

---

## 🤖 Models Implemented

1. WaterNet
2. UWCNN
3. FUnIE-GAN
4. UGAN (GAN-based Underwater Image Enhancement)
5. Real-ESRGAN
6. Shallow-UWNet
7. WaterMamba
8. WaterNet + Real-ESRGAN
9. waterNet + watermamba
